## Lab Questions

### In plain English describe the function and use of a multiplexer.
We created a 4 to 1 bitstream, which shows that multiplexers have multiple inputs and one output. 

### In plain English describe the function and use of a demultiplexer.
We created a 1 to 4 bitstream, which shows that a demultiplexer is the opposite of a multiplexer and has one input and multiple outputs.
