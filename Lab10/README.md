## Lab Questions

### What is difference between edge and level sensitive circuits?

Edge sensitive circuits are much more responsive and update more frequently.

### Why is it important to declare initial state?

If there is no initial state, the program doesn't know where to begin, and functions won't run correctly.

### What do edge sensitive circuits let us build?

Edge sensitive circuits let us build data storage with no lag time.
