## Lab Questions

### 1 - How might you add more than two bits together?

	By using multiple adders that wire into each other.

### 2 - What is the importance of the XOR gate in an adder?

	The XOR gate allows for calculating addition equations without the sum bit generating a carry.

### 3 - What is the largest number a two bit adder can handle? What happens when you go over?

	The largest number a two bit adder can handle is 3. If you go over, the arithmetic overflows, resulting in zero or a negative number.
